# 📖 Sobre o Projeto

A **TullyPhoto Landing Page** foi criada para apresentar um estúdio de fotografia de forma moderna e profissional.

O objetivo da página é:

- apresentar o portfólio fotográfico  
- divulgar serviços oferecidos  
- aumentar conversões de clientes  
- fornecer uma experiência visual elegante  
- funcionar perfeitamente em **desktop e mobile**

A landing page foi desenvolvida com foco em **design limpo, carregamento rápido e navegação intuitiva**.

# 📦 Como Executar o Projeto

```bash

```

Entre na pasta do projeto:

